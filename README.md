# JanNiti

**From Public Voice to Public Policy.**

JanNiti is an independent, citizen-driven civic-tech platform where people identify public problems, discuss solutions, build evidence, and develop better policy recommendations — inspired by initiatives like vTaiwan.

## Pages

- `index.html` — Homepage
- `trending-issues.html` — Browse and filter active policy issues
- `propose-issue.html` — Submit a new issue (minimal personal data: email only required, optional display name/state, no phone/address/ID)

## Status

Static front-end prototype (beta). No backend yet — forms are UI-only pending Supabase integration.

## Stack (planned)

- Frontend: static HTML/CSS/JS (for now), React later if needed
- Backend: Supabase
- Email: Resend / Brevo (for subscribe + issue confirmation)
